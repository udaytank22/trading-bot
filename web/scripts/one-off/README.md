# One-Off Standardization Scripts

This folder contains historic PowerShell scripts used during the **May 2026 Theme Standardization Pass** for TradeMind UI (`web/src`).

## Contents
- **`fix_all_theme.ps1`**: Automated replacement pass for un-prefixed table and section background/text color tokens across feature components.
- **`fix_modal_themes.ps1`**: Automated replacement pass for drawer/modal backgrounds, borders, and input text styling to support light/dark modes seamlessly.
- **`fix_table_text.ps1`**: Automated replacement pass for table cell, header, and footer text elements to ensure high contrast in both themes.

## Usage Note
> [!IMPORTANT]
> These scripts were executed for a one-off migration and are retained strictly for reference. They are not intended for regular automated build or maintenance workflows.
